# Crab Watch 0.11.0 Beta

This release marks the transition from analysis development to release hardening.

## Included

- post-game-only forensic analysis flow
- historical context over the recent 300 games with additional account context
- critical-position selection
- timing analysis when clock data is available
- Stockfish 18 post-game analysis
- personal engine baseline with scored-position validation
- temporal engine-trend analysis
- change-point and similar-position evidence
- conservative evidence fusion with no unsupported cheating probability
- reproducible Chrome extension packaging and release validation

## Release status

**Beta / draft-store ready after final asset and installation validation.**

The package gate intentionally remains closed until the final 48x48 and 128x128 PNG icons are present, the release validator passes, and the packaged extension has been manually installed and tested in Chrome.
