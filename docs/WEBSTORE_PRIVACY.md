# Crab Watch Privacy Disclosure

Crab Watch performs post-game analysis only. It does not analyze chess positions or provide move recommendations while a human-vs-human Chess.com game is in progress.

## Data used

When a completed game is reviewed, Crab Watch may access publicly available Chess.com player and game data for the opponent, including recent game history and account context. It also uses the completed game's moves and, when present, clock annotations.

## Local processing

Analysis is performed in the extension using locally bundled code, including Stockfish 18. Recent game history and analysis results may be cached in Chrome extension storage so repeated reviews do not unnecessarily repeat the same public-data requests.

## What Crab Watch does not do

Crab Watch does not sell personal data, does not use browsing history for unrelated purposes, and does not perform live-game engine assistance.

## Evidence and limitations

Crab Watch reports anomalous evidence and review signals. It does not determine that a player cheated, and it does not present an unsupported probability of cheating.
